# 《∞/1 秒》大模型游戏提报 · 网页版

由 `snow大模型游戏提报.pptx` 转换而来，页面 UI（进度条、翻页交互、总览模式、黑白版式）模仿老师的 ai-ppt 网页版，内容与排版保持原 PPT 不变。

## 打开方式

- **直接双击 `index.html`** 用浏览器打开即可；或
- 起一个本地服务器（推荐，加载更稳）：

  ```bash
  cd site
  python3 -m http.server 8823
  # 浏览器打开 http://localhost:8823
  ```

## 操作

| 按键 / 手势 | 功能 |
| --- | --- |
| `←` `→` / `PageUp` `PageDown` / `空格` | 翻页 |
| `Home` / `End` | 第一页 / 最后一页 |
| `O` 或双击空白处 | 总览模式（点击卡片跳页） |
| `F` | 全屏 |
| 点击底部进度条 | 跳到对应页 |
| 两侧边缘悬停点击 `‹` `›` | 上一页 / 下一页 |
| 触屏左右滑动 | 翻页 |
| 地址栏 `#N` | 直达第 N 页（如 `index.html#8`） |

## 视频说明

全部 14 个视频设为 `muted + autoplay + loop`：**进入页面自动循环播放，翻离页面自动暂停并复位**，回到该页从头再播（与 PPT 放映体验一致）。

## 文件结构

```
site/
├── index.html        # 全部页面 + 样式 + 交互
└── assets/
    ├── img/          # 原 PPT 内嵌图片（含视频封面帧）
    └── media/        # 原 PPT 内嵌视频（14 个 mp4）
```

坐标映射：PPT 版面 13.33in × 7.5in → 网页舞台 1280×720（1 英寸 = 96px），所有元素按原坐标 1:1 还原；整页随窗口等比缩放。
