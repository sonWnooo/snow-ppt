# ∞/1s · snow 大模型游戏提报 — 网页版

由 `snow大模型游戏提报.pptx` 转换而来，界面与交互仿照老师的网页 PPT
（https://fangke-justcan.github.io/ai-ppt/）：1280×720 舞台自适应缩放、
交叉淡入 + 上浮入场动画、底部进度条、两侧点击翻页、总览模式、哈希定位。
PPT 原排版未做任何改动（每页为 2560×1440 高清渲染图）。

## 怎么打开

- 直接双击 `打开网页版PPT.bat`（或双击 `index.html`）即可在浏览器中放映；
- 或者在本目录起一个静态服务器后访问，例如：
  `powershell -NoProfile -ExecutionPolicy Bypass -File ..\work\serve.ps1`
  然后打开 http://127.0.0.1:8642/

## 操作方式（与老师的 PPT 一致）

| 操作 | 效果 |
| --- | --- |
| → / ↓ / 空格 / PageDown / 滚轮 / 点右侧边缘 | 下一页 |
| ← / ↑ / PageUp / 点左侧边缘 | 上一页 |
| Home / End | 第一页 / 最后一页 |
| O | 总览模式（缩略图，点击跳页） |
| F | 全屏放映 |
| 触屏滑动 | 翻页 |
| 地址栏 #1 ~ #13 | 直接跳到某一页 |

## 视频说明

PPT 里的 13 段视频（封面、角色动作、场景漫游、交互设定等）已按 PPTX 内的
原始坐标精确叠放，进入相应页面即**自动播放、循环播放**（静音，等同循环动图），
离开该页自动暂停并复位。视频文件在 `videos/`，页面渲染图在 `slides/`。
